# ReadDaily 品牌视觉设计说明

## 设计概念：「晨报之窗」
三层语义，一层比一层具体：
1. **晨光日出**（每日）——橙金色日轮 + 表盘式射线：报纸每天清晨与你相见，射线如钟表刻度暗示"每日定时"
2. **报纸版面**（读报）——白色报纸微倾 8°，红报头条、排版线、图片位：一眼即"报纸"
3. **折角翻开 + 未读红点**（进行时）——右下折角露出晨光，右上未读红点（带深色描边便于浅色底识别）：今日内容在等你

## 色板（扁平渐变风）
| 用途 | 色值 |
|---|---|
| 底（深蓝晨曦） | #10243F → #1D4A7A（对角渐变） |
| 晨光（日+射线） | #FFC46B → #FF6B35（上下渐变） |
| 报纸 | #FFFFFF → #EEF2F6 |
| 报头红 | #D13B2F |
| 文字/辅助 | #12293F（字标）· #5B7186（副标）· 线条 #9FB2C8/#C3D0DF |

## 结构
- **图标**：1024×1024 圆角方形（rx=200 ≈ iOS 图标比例），内容区居中，留白 ≈ 1/8
- **字标组合**（Lockup）：图标 400px + "ReadDaily"（Helvetica Neue 700，#12293F）+ 中文副标"读报 · 每日新闻引擎"（52px，#5B7186）+ 橙色短下划（品牌色呼应）

## 使用说明
- 深底版本适用于深色启动页/门户；浅色场景用报头红+深蓝文字即可（如需浅底变体，把底色换为 #F6F8FB 并把报纸描边加 #D8E1EA）
- 中文"读报"已简化成报头条线，跨语言、跨平台无需字体授权；字标保留拉丁 "ReadDaily" 确保任何机型同构
- 若希望图标加"R"字母或"日"字型，可在下一轮迭代调整
