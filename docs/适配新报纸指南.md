# 适配新报纸指南（约 0.5-1 天/家）

1. **登记**：`sources.json` 加条目（id/name/channel/entry/…，enabled=false）
2. **探测**：`python3 skills/newspaper-fetch/scripts/fetch.py --probe <id> --date 今天`
   - 先试已知 pattern；无果则 web 搜索"报纸名+数字报/电子报"找真入口（frameset/SPA/翻书/API）
3. **渠道归类**：
   - 方正版式（node_XX.html + content_*.html）→ `founder`（配 index_url 或 node_tpl + pic_tpls）
   - 当日 index.json/pagePath → `cms_index`
   - JSON API（period/edition/article）→ `paper_api`
   - 微信读报 → `wechat_read`（account.biz + title_prefix）
   - 翻书（yunzhan365 等）→ 图片型：复用 yunzhan 技能思路（+OCR），暂不支持自动
4. **验收**：连续 3 个工作日 `readdaily fetch --source <id> --date …` 全通 + 期号/版数连续性 + 文本量合理
5. **固化**：enabled=true + note 记录通路与证据；把算法/模板写回适配器（通用优先，别做只此一家的 hardcode）

## 常见坑
- 首页 JS 壳 ≠ 无数字报：找 `window.layoutData`/`index.json`/`.js` 里的 API
- 季度/月份补零差异（202609 vs 2026-09）——pattern 里都试
- WAF 目录 403 → 显式文件直链往往放行（如农民日报）
- SPA 匿名接口常在 `/uv/`（无鉴权预览通道）
