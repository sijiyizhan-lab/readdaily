# 故障排查

| 症状 | 原因 | 处置 |
|---|---|---|
| launchd 任务失败 exit 1，err 有 PermissionError | macOS TCC 拦截（路径在 ~/Downloads|Documents） | 数据根改用 READDAILY_ARCHIVE（默认已安全） |
| 搜狗搜索空壳（news-list 缺失，len<10K） | UA 指纹限流 | 等待 10 分钟；不要连刷；版本号对应真实 Chrome |
| 微信文章 首页 404/“已删除” | 签名 URL 过期/Referer 不符 | 走离线回退（本地已有产物）或重新触发搜索 |
| 某源 403/404 空壳 | 站点反爬/改版 | `--probe` 重新定位 pattern；WAF 目录封禁用显式文件直链 |
| OCR 结果乱码 | 非 Vision 路径/字体 | 仅 macOS；确认 bin/vocr 由 swiftc 构建 |
| 版名异常（带引号/空名） | 版面 nav 结构差异 | 适配器版名正则按当期页锚定；下期自动刷新 |
| 今日未收录某源 | 当日版面偶发（会议/停刊） | 看 `_dailylog.jsonl`；次日自动连续校验提示缺口 |
| Codex 中技能不可见 | CLI 版本不支持 skills 自动加载 | 直接让它 `python3 scripts/readdaily.py …`；AGENTS.md 在仓库内自动生效 |
