# Read Daily 0.3.0

Read Daily 0.3.0 将 `readdaily` 封装为原生 macOS 每日读报工作台。应用围绕固定八报、原始证据、人工校对与中文知识卡片设计；Release 不包含任何报纸正文或版面数据。

## 下载文件

- `Read-Daily-v0.3.0-macOS-arm64.zip`
- `Read-Daily-v0.3.0-macOS-arm64.zip.sha256`

## 运行条件

- Apple Silicon Mac
- macOS 13 或更高版本
- Python 3；应用会读取 `READDAILY_PYTHON`，或探测 Homebrew 与系统常见安装位置
- 只有在线抓取中国建设报并生成 PDF 时需要 Chrome 或 Chromium

当前包采用 ad-hoc 签名，未使用 Apple Developer ID 公证。解压后首次启动，请在 Finder 中右键 `Read Daily.app`，选择“打开”。不要关闭系统级安全保护。

## 本版重点

- 人民日报、光明日报、经济日报、中国建设报、科技日报、农民日报、南方日报、北京日报固定八报
- 按日期与中央党报/部委行业报/地方党报分组，缺报明确显示
- 版次真实缩略图；没有版图时明确显示不可用占位
- 原版图在上、OCR 原文与校对在下；原版支持 25%–400% 缩放
- 原始 OCR 不可覆盖；文章块标题、顺序和空白按后端结构呈现，校订文本、校对状态和疑点独立保存
- 三张本地 SVG 图片 Banner，8 秒轮播；提供持久暂停/继续，悬停、聚焦或减少动态效果时也会暂停
- 天气文字、日期、每日获取/阅读动作与右侧中文摘要工作栏
- 默认进入今天，即使尚无归档也可立即抓取；历史日期仍可切换
- 八报均可逐版增量保存本地草稿；正式写入 Obsidian 仍只允许中国建设报，并要求整期校验、预览确认和编辑版本一致
- 980 点起使用响应式纵向工作区；状态文字对比度、轮播语义和完成提示已增加可访问性保障

## 数据与安全边界

- 下载包内置工作台所需脚本、OCR helper 与许可证，不要求另行克隆 GitHub 仓库
- 报纸数据默认保存在 `~/Library/Application Support/readdaily/news-archive`
- 阅读状态与草稿只写归档目录；归档与 Vault 相同或为符号链接别名时会拒绝写入
- 归档与 Vault 父子重叠也会被所有读写入口拒绝；读写前从原始配置路径逐级以 `O_NOFOLLOW` 固定目录句柄，再完成隔离校验并在整个操作中复用，祖先目录被换成软链时不会越界写入
- 同日抓取使用进程锁和唯一临时文件；来源日期、版次链接、图片链接及最终重定向日期不一致时拒绝落盘
- 所有已发现版次必须使用真实编号并严格连续唯一；所有文章必须归属已发现版次，缺版、孤立链接、超上限或任一请求失败均整期拒绝落盘
- 网络版图需通过系统 ImageIO 的真实像素解码；通用版面至少为短边 1000、长边 1400 像素，高分辨率渠道继续使用更高门槛，仅伪造格式标记、尺寸或结束边界的数据不会进入归档
- 移除文章数量、正文长度、HTML 窗口和段落数量的静默裁剪，OCR、短段落、长短标题与结构化文章块均保留完整尾部内容
- 在线抓取与解析按整期原子刷新；失败恢复旧期，成功换刊会使旧摘要、发布与归档状态失效
- 本地 PDF 校验报头日期与逐页清单，并基于稳定快照完成 OCR；无法确认日期、页码缺失、重复、越界、文件缺失或软链引用均阻止发布
- 发布计划绑定报纸证据摘要和当前持久草稿摘要，应用前再次核验；草稿、阅读动作及发布/回滚采用统一锁序、内容级 CAS、原子替换和预检快照
- Vault 发布使用独立于 archive/Vault 的持久事务哨兵，计划、快照、事务与哨兵均通过固定目录句柄读写，关键 rename 与目录变更同步父目录；异常中断只能续作或受控恢复，不能跨归档并发覆盖
- 日报知识卡以“日期 + 中文报纸名”作为稳定路径，期号修正不会产生重复节点
- 未点击发布确认前不会写入 Obsidian
- 项目不绕过登录、验证码或付费墙
